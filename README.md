# Time Stamp Studio

A clean, lightweight Discord timestamp generator that makes creating and sharing dynamic timestamps simple.

Generate Discord timestamps for any date, time, and timezone, preview how they appear in Discord, and copy them instantly.

## Features

- **Custom Date Picker** – Select any date with an intuitive calendar.
- **Time Selection** – Configure hours, minutes, and AM/PM.
- **Timezone Support** – Choose from common timezones or enter your own.
- **Live Countdown** – See how much time remains until your selected date and time.
- **Discord Timestamp Formats** – Generate all seven supported Discord timestamp styles.
- **Announcement Builder** – Compose announcements with generated timestamps.
- **Live Preview** – Preview your announcement before sharing it.
- **One-Click Copy** – Copy individual timestamps or complete announcements.
- **Monochrome Interface** – Minimal black, white, and grey design.
- **Responsive Layout** – Works across desktop and mobile screens.

## Discord Timestamp Formats

Time Stamp Studio supports all standard Discord timestamp formats:

| Format | Display |
|---|---|
| `t` | Short Time |
| `T` | Long Time |
| `d` | Short Date |
| `D` | Long Date |
| `f` | Short Date and Time |
| `F` | Full Date and Time |
| `R` | Relative Time |

## Getting Started

No installation or dependencies required.

1. Open the website.
2. Select your desired date.
3. Set your time and timezone.
4. Choose the Discord timestamp format.
5. Copy your generated timestamp.
6. Paste it directly into Discord.

## Hosting

Time Stamp Studio can be hosted for free using **GitHub Pages**.

1. Fork or clone this repository.
2. Ensure the main HTML file is named `index.html`.
3. Open your repository's **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` directory.
6. Save your settings.

Your website will be available at:

`https://ARSSANTO.github.io/Time-Stamp-Studio/`
